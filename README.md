# narezka

**Нарезка** — мобильный видеоредактор в духе CapCut, который работает прямо в браузере. Один файл `index.html`, без сервера и без установки.

## Как запустить

- Открой `index.html` в Chrome на телефоне или компьютере.
- Или включи GitHub Pages (Settings → Pages → ветка `main`) и открывай по ссылке.

## Что умеет

- **Монтаж:** видео и фото из галереи, таймлайн с курсором по центру, зум двумя пальцами, обрезка за края, перестановка клипов.
- **Клипы:** разделить, скорость 0,2–8×, громкость до 200%, стоп-кадр, извлечь звук.
- **Текст и графика:** 13 стилей, 10 шрифтов, анимации текста, стикеры, «картинка в картинке».
- **Картинка:** 15 фильтров, цветокоррекция, 11 переходов, 20 эффектов, 7 форматов кадра (9:16, 16:9, 1:1…).
- **Звук:** музыка с телефона, около 250 встроенных звуков по категориям (переходы, мемы, удары, интерфейс, голоса, магия, мультики, джинглы, животные, атмосфера, хоррор): записи CC0 из открытых библиотек (см. `sfx/CREDITS.md`) и синтез на устройстве; озвучка с микрофона.
- **Субтитры:** автоматически распознают речь в видео и озвучке (Whisper прямо на телефоне, русский, английский, украинский), расставляют фразы по времени; список фраз можно править вручную.
- **Текст в речь:** пишешь текст, выбираешь голос (Денис, Дмитрий, Руслан, Ирина) и скорость — речь встаёт на таймлайн отдельной дорожкой, по желанию с субтитрами по фразам.
- **Проекты:** отмена/повтор, автосохранение, экспорт в MP4/WebM 480p–1080p.

Проекты и файлы хранятся только в браузере на устройстве (IndexedDB) и никуда не загружаются.

## Озвучка текста

Работает прямо на телефоне, без сервера:

- **Голоса** — [Piper](https://github.com/rhasspy/piper) (русские модели `ru_RU`, около 60 МБ каждая). Голос скачивается с Hugging Face один раз и сохраняется в браузере, дальше работает без интернета.
- **Фонемизатор** — espeak-ng, собранный в WebAssembly ([diffusionstudio/piper-wasm](https://github.com/diffusionstudio/piper-wasm)), лежит в папке `tts/`.
- **Нейросеть** запускается через [onnxruntime-web](https://github.com/microsoft/onnxruntime) с CDN.

Второй вариант — **Fish Audio** ([fish.audio](https://fish.audio)): озвучка через их облако твоим API-ключом. Ключ вводится в редакторе и хранится только в браузере, в репозиторий он не попадает. Можно выбрать русский голос из их библиотеки, свои голоса или вставить ID голоса. Платно по их тарифам, нужен интернет.

Для первой загрузки голоса нужен интернет. Лучше всего открывать через GitHub Pages: тогда файлы из `tts/` берутся из этого репозитория.

Лицензии: Piper и piper-wasm — MIT, espeak-ng — GPL-3.0, условия каждого голоса — в его `MODEL_CARD` в [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices).

## Приложение для Android (APK)

Папка `android/` — обёртка, которая превращает редактор в приложение «Нарезка»:
- страница работает из самого APK, без интернета (кроме загрузки голосов);
- выбор видео и фото из галереи, запись голоса с микрофона;
- готовое видео сохраняется в галерею: `Movies/Нарезка`;
- Fish Audio вызывается через приложение, без ограничений браузера.

Сборка без Android SDK: `python3 android/build.py --android-jar android.jar --dx dx.jar` (android.jar — из Sable/android-platforms, dx — собранный из AOSP dalvik). `android/signing-key.pem` — ключ подписи: с ним новые версии ставятся поверх старой без потери проектов.
